# 🧠 About Project

This project is an interactive **Real Estate Intelligence Dashboard** built using Power BI to analyze property market data and support data-driven decision-making. The dashboard transforms raw real estate datasets into meaningful insights through dynamic visualizations, KPIs, and advanced DAX calculations.

---

# 🔍 Project Objectives

* Monitor overall property market activity
* Analyze sales and rental performance
* Track listing trends over time
* Understand property demographics and age distribution
* Evaluate furnishing status and property composition
* Analyze amenities such as pools, parking, elevators, and gyms
* Support strategic real estate decision-making

---

# 📊 Dashboard Features

* Interactive KPI cards with trend indicators
* Property sales and rental analysis
* Dynamic year-over-year comparison summaries
* Property age segmentation
* Furnishing status analysis
* Amenity insights and composition metrics
* Interactive slicers and filters for exploration
* Modern and responsive dashboard UI

# 💡 Business Value

This dashboard helps stakeholders:

* Monitor real estate market performance

* Gain a comprehensive overview of property market dynamics
